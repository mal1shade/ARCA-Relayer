Aplikasi otonom cerdas yang membacakan pesan WhatsApp kamu secara otomatis menggunakan teknologi Text-To-Speech. Tetap fokus di jalan atau saat bekerja tanpa harus menyentuh layar. Build by Akmal Maula Aditya

Kebijakan Privasi (Privacy Policy)

⚠️ Cara Pemasangan Penting:

  1. Unduh file APK melalui tombol di atas.
  2. Buka file tersebut. Jika muncul peringatan "Play Protect", klik "More details" (Detail lainnya) lalu pilih "Install anyway" (Tetap instal).
  3. Setelah terinstal, buka A.R.C.A Relayer.
  4. Sistem akan meminta izin Akses Notifikasi. Wajib diaktifkan agar A.R.C.A bisa membaca pesan yang masuk.
